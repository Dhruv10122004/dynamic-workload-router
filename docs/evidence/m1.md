## Runbook for the hardware ACs (owner)

**Windows laptop (controller)** — PowerShell in the repo:
1. `Copy-Item .env.example .env`, then edit `.env`:
   - `DWR_BIND_HOSTS=127.0.0.1,<LAN or Tailscale IP of this laptop>` (`ipconfig` / `tailscale ip -4`)
   - `DWR_WORKER_TOKENS=edge-1:<secret>,fog-1:<secret>` and a real `DWR_ADMIN_TOKEN`
2. Firewall (elevated PowerShell), scoped to the LAN; for Tailscale use `-RemoteAddress 100.64.0.0/10`:
   `New-NetFirewallRule -DisplayName "DWR controller 8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -RemoteAddress LocalSubnet -Action Allow -Profile Private`
   and check the network profile is Private: `Get-NetConnectionProfile`.
3. `.\.venv\Scripts\python -m controller`

**Linux laptop (Fog worker)**:
4. `git clone` / `git pull`, `git checkout v1`, then `./scripts/setup.sh`
   (worker id `fog-1`, controller URL `http://<windows-ip>:8000`, token = fog-1's secret).
   The script ends with `curl /api/v1/health`, which must print JSON.
5. `.venv/bin/python -m worker.agent`
