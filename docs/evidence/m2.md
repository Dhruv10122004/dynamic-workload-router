## Runbook for the hardware ACs (owner), together with M1

Windows (normal PowerShell, repo root; add `-ExecutionPolicy Bypass` if scripts are blocked):
1. `.\scripts\setup.ps1 -BindIp <this laptop's LAN/Tailscale IP> -EdgeSlots "2;4"`
   (note the fog-1 token it prints). Firewall rule: elevated prompt, command printed by setup.
2. `.\scripts\start.ps1` → controller + edge-1 running, `ready: fresh workers = edge-1`.
Linux:
3. `./scripts/setup.sh` (worker id fog-1, URL `http://<windows-ip>:8000`, the fog-1 token), then
   `.venv/bin/python -m worker.agent`.
Checks from Windows (`$b = "http://127.0.0.1:8000/api/v1"`):
- AC-1.1 / AC-2.1: `Invoke-RestMethod $b/workers` twice ~1 s apart: both fresh, `heartbeat_age_s` < 2.
- AC-2.2: for each of edge-1, fog-1 submit
  `{"type":"cpu_hash","params":{"iterations":5000000},"placement":"<w>"}`,
  `{"type":"data_digest","params":{"input_bytes":52428800,"rounds":5},"placement":"<w>"}`,
  `{"type":"mem_touch","params":{"mem_mb":256,"hold_s":10},"placement":"<w>"}`;
  while RUNNING: `Get-Process -Id <pid>` (Edge) / `htop` filter `worker.workloads` (Fog). Screenshots.
- AC-2.3: fog-1 data_digest record: `transfer_bytes` = 52428800, `transfer_s` > 0.
- AC-2.4: mem_touch records: `exec_s` ≥ 10, `result.hold_s_actual` ≈ 10.
5. `.\scripts\stop.ps1`.
