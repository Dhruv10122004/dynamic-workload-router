## Runbook for the hardware ACs (owner)
Copy the new code to the Linux laptop first (zip again; keep its `.env`). For AC-4.3 only,
set `DWR_TEST_MODE=1` in the Windows `.env` and restart the controller; set it back to 0
afterwards (test-only parameters must never be used in experiments).
`$b = "http://127.0.0.1:8000/api/v1"` and
`function sub($w, $body) { (Invoke-RestMethod "$b/jobs" -Method Post -ContentType application/json -Body ($body + @{placement=$w} | ConvertTo-Json)).job_id }`
1. **AC-4.1** (each of edge-1, fog-1): `$j = sub fog-1 @{type="cpu_hash"; params=@{iterations=5000000}}`,
   wait for RUNNING, note `pid`, then `Invoke-RestMethod "$b/jobs/$j/cancel" -Method Post`.
   Record → `state`, `kill_reason`, `termination_verified`, `kill_latency_ms`. Check the pid is gone:
   Windows `Get-Process -Id <pid>` (error expected), Linux `ps -p <pid>` (no row).
2. **AC-4.2**: `sub fog-1 @{type="cpu_hash"; params=@{iterations=5000000}; timeout_s=1}` → KILLED(timeout).
3. **AC-4.3** (test mode): `sub fog-1 @{type="mem_touch"; params=@{mem_mb=16; hold_s=20; actual_mb_override=400}}`
   → KILLED(memory_limit).
4. **AC-4.4**: `sub fog-1 @{type="mem_touch"; params=@{mem_mb=64; hold_s=30}}`; once RUNNING, turn
   off Wi-Fi on the Linux laptop. Within ~6 s: `Invoke-RestMethod "$b/workers/fog-1"` → `stale`
   true, job UNKNOWN. Submit `sub auto @{type="cpu_hash"; params=@{iterations=1000000}}` → edge-1.
   Turn Wi-Fi back on after ~40 s → the job shows SUCCEEDED (transitions … UNKNOWN → SUCCEEDED).
5. **AC-4.6**: `sub fog-1 @{type="mem_touch"; params=@{mem_mb=64; hold_s=30}}`; once RUNNING, from a
   second Linux terminal run `pkill -9 -f worker.agent` (not Ctrl+C: that signals the whole
   process group and would kill the job too). Check `ps aux | grep [w]orker.workloads` shows the
   orphan, then start the agent again. Expect FAILED(agent_restart),
   `termination_verified` true, and `ps aux | grep worker.workloads` empty.
6. **AC-4.7**: `python -m experiments.burst --n 30 --mix mem` in one window; meanwhile stop the
   controller only (`Stop-Process -Id (Get-Content var\run\controller.pid)`), wait 10 s, start it
   (`.\scripts\start.ps1` refuses while the Edge agent runs, so: `.\.venv\Scripts\python -m controller --log-file var\logs\controller.log`).
   Afterwards: every job terminal, `python -m experiments.audit` OK, no job with two
   decisions placing it on two workers.
7. **AC-4.5**: on each machine, `python -c "from worker.journal import Journal; import pathlib; print(max(Journal(pathlib.Path('var/worker/journal.db')).spawn_counts().values()))"` → `1`.
