## How the views map to the API (AC-5.1)
- Header: `GET /health` (status, fresh workers), `GET /scheduler` (policy, host-busy on/off).
- Overview: `GET /overview` (every tile and both tables; definitions in D-022),
  `GET /events?order=desc` (feed).
- Workers: `GET /workers` (all fields; badges from `fresh`, `host_busy`, `draining`;
  capabilities printed as reported, `not_enforced` highlighted); drain/enable POSTs.
- Jobs: `GET /jobs?order=desc&limit=&state=`; cancel = `POST /jobs/{id}/cancel`.
- Decisions: `GET /decisions` (policy, chosen, eligible, ineligible reasons, decision_us).
- Submit: `GET /catalog` (types, bounds, defaults), `GET /workers` (placement list),
  `POST /jobs`.
Nothing is computed in the browser except formatting (times, decimals, RAM % from
`mem_total_mb`/`mem_available_mb`).
