## Runbook for the hardware runs (owner)
Prerequisites:
- **Both laptops on mains power** for the reference and every block (battery ≈ 1.7× slower).
- Same network for the whole block; set `"network"` in each config (e.g. `"hotspot"`).
- Close other apps on both (idle rule: host CPU < 10% for 30 s; if never reached, add
  `"idle_cpu_pct": 20` to the config: it is recorded).
- Linux code re-copied; Windows `.\scripts\stop.ps1; .\scripts\start.ps1`; Linux agent running.
- Windows once: `.\.venv\Scripts\pip install -r requirements-analysis.txt` (matplotlib).
- Power settings: no sleep during the sweep.

1. **Reference** (≈ 5 min): `.\.venv\Scripts\python -m experiments.reference --network <net>`
   → `experiments/reference.json`. Commit it: every trace depends on it.
2. **Pilot** (≈ 15 min): `.\.venv\Scripts\python -m experiments.sweep experiments\configs\pilot.json`,
   then `... -m experiments.analyze experiments\results\pilot`. Sanity check `report.md`:
   EdgeOnly overflows more than LocalFirst at load 2, LocalFirst puts work on fog-1.
3. **Full sweep** (≈ 5–6 h): `... -m experiments.sweep experiments\configs\sweep.json --dry-run`,
   then without `--dry-run` (`*> sweep.log` to keep a log). If it stops, run the same
   command again: finished runs are skipped.
4. **Ablation** (≈ 1 h): first on Linux
   `.venv/bin/python -m experiments.stress --cpus all --target-host-pct 85 --follow-runs --block ablation --admin-token <DWR_ADMIN_TOKEN of the Windows .env>`,
   then on Windows `... -m experiments.sweep experiments\configs\ablation.json`.
5. **Analysis**: `... -m experiments.analyze experiments\results\sweep` and `...\ablation`
   → `analysis\report.md`, `summary.csv`, `runs.csv`, `ablation.csv`, plots.
